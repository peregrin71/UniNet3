# UniNet Boundaries and Non-Claims v1

Date: 2026-03-30  
Purpose: explicit anti-overclaim contract for transparent and defensible communication.

## 1. General Rule

If a claim is not tagged `proved` in `UNINET_PROOF_STATUS_LEDGER.md`, it must not be stated as established fact.

## 2. Non-Claims (Current)

1. **No claim of full Standard Model derivation yet.**
   - Specifically, `U(1) x SU(2) x SU(3)` emergence is not yet theorem-level.

2. **No claim of completed microscopic-to-observable transfer closure in all sectors.**
   - Several matrix rows remain intentionally `deferred`.

3. **No claim of complete black-hole quantitative closure.**
   - Page/firewall/microstate statements are represented as deferred prediction pathways, not core proven outputs.

4. **No claim that collider/direct-detection nulls already prove non-particle dark matter branch.**
   - A detector coupling map is required before this can become a hard prediction.

5. **No claim of unique transfer operator family.**
   - Admissible family is constrained but not uniquely fixed.

6. **No claim that Noether promotions are complete.**
   - Current symmetry results include theorem-level and noether-like layers; full action-based Noether closure is pending.

7. **No claim that all cosmology channels are locked to multipole-level observables.**
   - CMB multipole forward map remains deferred.

## 3. Allowed Claims (Current)

1. Tier-0 locality/unitarity/buffering/chirality axioms are explicit.
2. Derived causal/latency/cone/order scaffolding in core is theorem-level where marked.
3. Queue/backpressure theorems and constraints are integrated in core and GR planning.
4. Falsifiability matrices provide hard-Popper packaging with explicit core-vs-deferred gates.

## 4. Language Policy

Use the following modal verbs only:

1. `proved`: only for ledger `proved` rows.
2. `postulated`: for model choices explicitly tagged `postulate`.
3. `deferred`: for missing-map/missing-proof/missing-threshold items.
4. `compatible with`: for observational consistency statements that are not unique predictions.

Forbidden phrasing (until promoted):

1. "UniNet derives the full Standard Model."
2. "UniNet resolves black-hole information paradox quantitatively."
3. "UniNet predicts collider nulls as a theorem."
4. "Noether theorems are fully established in all sectors."

## 5. Promotion Condition

A non-claim can be removed only when all are true:

1. It appears as `proved` or `postulate` with explicit status in proof ledger.
2. It has a concrete source anchor in core or governing program doc.
3. If observational, it has a binary reject criterion in a matrix row.
