# UniNet3 Workspace Layout

## Reader Entry Point

Start with [READERS_GUIDE.md](./READERS_GUIDE.md).

## Folder Structure

1. `docs\00_foundation\`  
   Core axioms and global structural constraints.
2. `docs\10_sections\`  
   Reader-facing sector documents for QM, GR, SM, cosmology, symmetry, and philosophy.
3. `docs\20_proofs\`  
   Technical proof notes supporting the section documents.
4. `docs\30_falsifiability\`  
   Matrices, indexes, and dependency maps connecting theory to observables.
5. `docs\40_governance\`  
   Standards, non-claims, notation, and proof-status tracking.
6. `docs\50_programs\`  
   Rigor plans, programs, and parameter-tracking documents.
7. `docs\60_paper\`  
   Paper-planning material.
8. `docs\90_archive\`  
   Historical notes and backlog material not on the main reading path.
